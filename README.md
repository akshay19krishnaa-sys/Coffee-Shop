## ✨ Features & Highlights

- **Hozon Editorial Frame**:
  - Top-left & top-right micro-copy (`THE ART OF COFFEE.` • `A sensory ritual. / A slower kind of greatness.`).
  - Vertical rotated typography: `COFFEE. CRAFTED. CULTURE.`.
  - Minimal circular `II` audio control toggling roastery ambient hum and motion.
- **3D Ingredient Parallax**:
  - Realistic roasted whole coffee beans with natural clefts, warm gradients, and surface sheen floating in 3D space.
  - Interactive mouse tilt and scroll-triggered radial float.
  - Golden crema particles and subtle ambient steam.
- **Storytelling Chapters**:
  - **Chapter 01 // Origins**: High-altitude volcanic terroir & meticulous hand selection (Huila, Yirgacheffe, Boquete).
  - **Chapter 02 // Roasting**: Thermodynamic roast curves, First Crack timing, and Maillard development.
  - **Chapter 03 // Brewing**: Precision extraction ratios, Kyoto cold drip towers, and variable pressure profiling.
- **Interactive Specialty Menu**:
  - Filter by category (*All*, *Single Origin*, *Espresso*, *Signature Cold*, *Handcrafted*).
  - Real-time size selection (8oz, 12oz, 16oz) with dynamic price calculation.
  - Item customizer (milk choice, sweetness level, extra shot) and slide-out cart drawer with simulated checkout.
- **Café Architectural Experience**:
  - Kyoto & Oslo architectural spaces, tactile cedar & blackened steel textures.
  - Responsive masonry gallery with full-resolution interactive lightbox.
- **Audio Sensory Experience**:
  - Web Audio API procedural brown-noise roastery synthesizer mimicking warm roastery ambiance and steam.
- **Fully Responsive**:
  - Tuned and verified from **320px small mobile** to **1440px+ ultra-wide desktop displays**.
  - 44px+ touch targets on all interactive controls.
  - Scroll lock on active modal/drawer states to prevent background jitter.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS 4 + Custom Typography (`Syne` & `Inter`)
- **Animations**: GSAP + ScrollTrigger
- **Physics Smooth Scroll**: `@studio-freight/lenis`
- **Icons**: Lucide React
- **Audio Engine**: Native Web Audio API Procedural Synthesizer

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/akshay19krishnaa-sys/Coffee-Shop.git
cd Coffee-Shop
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

### 5. Lint
```bash
npm run lint
```
